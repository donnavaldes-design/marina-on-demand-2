# Marina On Demand 3.3.0 — Chat Projects

Upload all four flat files to the existing repository root.

Build marker:
3.3.0-chat-projects

Chat organization added:
- Create custom Projects / chat folders.
- Filter conversations by Project.
- Move a chat into a Project.
- Move a chat back to All Chats.
- Rename chats.
- Delete chats permanently.
- Rename Projects.
- Delete Projects without deleting contained chats. Those chats return to All Chats.

Important product distinction:
- Projects organize conversation threads.
- Workspace stores durable business assets Marina creates or the user saves.

All project and conversation mutations are scoped to the signed-in user.

Everything from 3.2.0 Secure MCP OAuth remains included.
