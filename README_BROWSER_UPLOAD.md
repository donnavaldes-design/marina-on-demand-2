# Marina On Demand 3.0.1 — Live Web Research

Upload these four files to the ROOT of the existing GitHub repository and replace the current files:

Build marker:
3.0.1-live-web-research

New:
- Live OpenAI web search tool enabled in Coach Me, Create With Me, skills, and Action Mode.
- Explicit web/research/current/URL requests force a web lookup in normal chat modes.
- Marina can research public websites and publicly discoverable social/web presence.
- Current facts such as pricing, availability, events, trends and platform changes can be researched live.
- Web sources are stored with the assistant message and displayed as clickable source chips.
- Marina is instructed not to claim she viewed inaccessible pages or private/logged-in social content.
- Proprietary Marina methods remain authoritative and are not replaced by generic web advice.

Example test:
"Go to donnavaldes.com and learn about me through my site and public social media presence. Tell me what my brand communicates, what is unclear, and what I should fix first."

Important limitation:
Public web research is not the same as logged-in browser access. Some Instagram, Facebook, TikTok or LinkedIn content may not be publicly indexable. Marina should state that limitation when it occurs.
